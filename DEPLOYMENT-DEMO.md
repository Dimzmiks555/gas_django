# Публичная демонстрация GAS

Демо развёрнуто в /opt/apps/gas-demo, compose.demo.yaml. Для работы нужны локальные переменные окружения .env; секреты и базы данных не хранятся в Git. Вход в публичную демонстрацию и ограничения записи определяются серверной конфигурацией Caddy. Изменения формы защищены идентификаторами отправки, тесты: python manage.py test gas.test_submissions.
